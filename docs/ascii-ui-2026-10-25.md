# ASCII UI implementation and verification

Implemented the research brief's six priorities: independent interface scaling and map zoom, designation previews, grouped/searchable commands and favorites, optional labels and keyboard inspection, actionable priorities and commission delivery, and accessible themes/motion/focus styles.

The UI remains a view of the existing simulation. Preview eligibility uses the same `canDesignateTile` function as execution. Construction costs are quoted for completion; queueing does not reserve or spend materials. A shortage is a warning rather than a new game rule. Confirmation uses the current engine state and reports actual accepted/skipped counts.

Preferences use a separate validated, versioned browser-storage key. Old fortress save versions and engine rules are unchanged. Display text supports 14–28px, maps support 60–200% plus Fit, and the canvas backing store uses the device pixel ratio. DejaVu Sans Mono is bundled with its distribution license so the intended font does not rely on an external font service.

Map object lists and labels respect revealed terrain. Keyboard object cycling tracks identity so multiple entities on the same tile do not trap navigation or inspect the wrong dwarf. Escape exits inspection, then native Tab navigation leaves the map. New keyboard rectangles replace pending previews. Browser Ctrl/Cmd+F keeps its normal behavior. Search dialogs pause and restore the prior clock state.

Browser checks completed with the rendered DOM and element geometry:

- 1280×720: command search selects the brewery, dialog closure preserves an already paused clock, and the page has no horizontal overflow.
- Keyboard 2×2 brewery preview: three eligible tiles and one blocked stair tile; quoted cost is 9 stone and 6 timber. Confirmation accepts three, skips one, and leaves the stock unchanged until simulation work finishes.
- Keyboard replacement: a pending wall rectangle can be replaced by a new Shift+arrow selection; the next preview updates its eligible count and cost. Escape cancels it.
- 390×844 with 18px text: mobile navigation, category filtering, favorites, map controls, and scrollable map work without page-level horizontal overflow. Control rows scroll horizontally to retain map space.
- 1920×1080 with 28px text: settings remain reachable, panels reflow/scroll, map remains available, and no page-level horizontal overflow occurs. Smaller interface text and larger map zoom work independently.
- Save/reload/Continue restores the fortress and preserves the independently stored 18px/high-contrast/labels/reduced-motion preferences.
- Chronicle category filtering displays the matching entries newest first.
- Accepting the stone commission exposes current stock and deadline in the priorities strip; delivering from that strip confirms the reward and clears the ready notice.

Screenshot capture was unavailable in the browser connection, so no screenshots are claimed. Responsive geometry and functional behavior were checked directly. No physical touch device, gamepad, or screen reader test was performed. DPR backing-store logic is implemented; the browser session's actual DPR was 1.

Automated coverage adds engine/preview agreement for every tool, unaffordable queues, clipped rectangles, revealed-only points and notices, repeated chronicle grouping, and preference validation. Run `npm test`, `npm run typecheck`, `npm run lint -- --max-warnings=0`, and `npm run build` to repeat the checks.
